# 설명 그림

## 원칙
- **코드·문서에서 확인한 동작만** 그린다. 그리기 전에 해당 코드를 읽는다. 추측이 섞이면 그림에 "추정"이라고 쓴다.
- 숫자는 실제 값으로 계산해서 적는다. 너무 작은 값은 크게 그리고 "크게 그렸습니다"라고 밝힌다.
- 비교는 패널을 나란히: 지금 / A안 / B안. 권하지 않는 안은 제목에 표시하고 이유를 빨간 글씨로.
- 색을 일정하게: 파랑 = 원래 것, 주황 = 바뀌는 것·움직임, 초록 = 계산된 결과, 빨강 = 경고. 화살표로 순서를.
- 그림 아래에 ①②③ 순서 설명 3~5줄.
- 사용자가 설명을 반박하면 맞는지 따져 보고, 맞으면 바로 인정하고 그림을 고친다.

## 만드는 법
1. Python으로 좌표를 계산해 HTML + 인라인 SVG를 쓴다. 다각형 오프셋·교점·mm→px는 `scripts/geom.py`.
   한글은 글꼴 파일을 `@font-face`로 직접 지정한다(시스템에 한글 글꼴이 없을 수 있음).
2. `node scripts/render.js in.html out.png <폭> <높이>` → 2배 해상도 PNG(Playwright).
3. 결과를 **직접 열어 보고** 글자 겹침·잘림을 고친 뒤 보낸다. 패널 높이와 글자 자리를 넉넉하게.
4. 답에는 그림 요약 몇 줄과, 정해야 할 것 질문 하나.
